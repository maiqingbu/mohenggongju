# 章节类型规范

每种类型定义了不同的**逻辑控制台字段**、**起承转合锚点**、**收益校验项**。写章纲之前必须先选定类型。

---

## 类型总览

| 类型 | 一句话定义 | 核心爽感机制 | 典型场景 |
|------|-----------|-------------|---------|
| **打脸** | 被轻视后实力碾压 | 预期差 → 降维打击 | 被销售蔑视→全款刷卡 |
| **致富** | 财富数字暴增 | 余额跳动 → 支配感飙升 | 提现到账/收购资产/解锁商机 |
| **反转** | 读者认知被颠覆 | 假象 → 真相 | 敌人变盟友/好人变幕后黑手 |
| **装逼** | 低调出场震惊全场 | 平凡表象 → 强大本质 | 穿人字拖进会场/低调身份曝光 |
| **冲突** | 两方正面碰撞 | 对抗 → 压制/胜出 | 庭审/谈判/正面硬刚 |
| **暧昧** | 情感关系微妙变化 | 推拉 → 关系温度升降 | 并肩作战/深夜对话/意外接触 |
| **悬疑** | 抛谜—追踪—揭一角 | 好奇 → 部分满足 → 更大好奇 | 发现线索/追查/新谜题 |
| **推进** | 连接前后、布局铺陈 | 信息传递 → 期待蓄力 | 交接任务/获取情报/场景迁移 |

---

## 一、打脸

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **打脸对象** | 谁在轻视/羞辱主角 | 势利销售、HR总监、前妻 |
| **轻视理由** | 对方凭什么看不起主角 | 穿着寒酸、被裁员、没背景 |
| **打脸方式** | 主角用什么方式反抽 | 全款刷卡不试驾、当众播放证据 |
| **围观群众** | 见证打脸时刻的人群 | 展厅其他销售、恒太全体员工 |
| **打脸强度** | ★☆☆ ~ ★★★ | ★★★=当众揭穿+系统播报+地位逆转 |

### 起承转合锚点

```
[起] 主角以被低估的身份进入场景 + 反派施压/轻视（明写反派态度）
[承] 轻视升级/围观者站队/反派变本加厉（情绪压抑，让读者憋屈）
[转] 主角亮底牌/反抽（金句+关键画面，必须具象到动作和表情）
[合] 反派崩溃/围观者震惊 + 系统反馈（怨气/余额/技能播报）
```

### 本章收益校验

- [ ] 打脸对象受到实质打击（脸疼有画面）
- [ ] 围观群众有明确反应（不能只写"众人震惊"）
- [ ] 主角获得即时收益（钱/道具/地位/关系推进 至少一项）
- [ ] 打脸方式不是重复前章套路

### 常见错误

- 打脸对象太弱，赢了也没爽感——反派必须有压迫力
- 只写主角做了什么，不写围观者的反应——爽感来自"被看到"
- 打脸节奏过慢——从轻视到反抽控制在 300-500 字内

## 二、致富

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **收益来源** | 钱从哪来（系统/投资/收割反派） | 怨气提现、收购债权、资产增值 |
| **具体金额** | 本章收益数字 | 提现200万、资产破千万 |
| **收益触发** | 什么事件触发了收益 | 反派崩溃、合同签约、系统解锁 |
| **支配方式** | 主角怎么花/怎么用这笔钱 | 全款购房、收购公司、发工资稳住团队 |
| **资产里程碑** | 本阶段总资产达到什么水位 | 总资产突破两千万 |

### 起承转合锚点

```
[起] 发现机会/资金需求出现（需要花钱的场景）
[承] 操作过程（主角用什么手段获取收益——收购/提现/收割）
[转] 收益到账（余额跳动的具象画面——POS机、短信通知、系统面板）
[合] 余额更新 + 解锁新能力/新选择（钱带来什么新可能性）
```

### 本章收益校验

- [ ] 有了具体数字（不写"大赚一笔"，写"卡里躺着一千二百万"）
- [ ] 收益来源清楚（系统提现/资产收购/分红 等等）
- [ ] 花钱有画面（不是"他买了房"，是"他在合同上签字时笔尖划破了纸"）
- [ ] 钱带来了新的选择权（不是只存着，是解锁了下一步动作）

### 常见错误

- 数字太虚——必须给具体金额，让读者能算账
- 只赚钱不花钱——钱的意义在于改变选择权
- 收益来源和主线脱节——为爽而爽的提现没有叙事价值

## 三、反转

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **被颠覆的认知** | 本章之前读者/角色相信什么 | 钱文忠是赵建国的忠犬 |
| **真相** | 实际是什么 | 钱文忠一直在暗中收集证据 |
| **反转触发点** | 什么事件让真相暴露 | 一份被"不小心"寄出的账本 |
| **受影响者** | 谁因为反转改变立场/处境 | 主角、赵建国、恒太董事会 |
| **可信度铺垫** | 前面哪章埋了这个反转的伏笔 | 第X章钱文忠"不小心"多看了林白一眼 |

### 起承转合锚点

```
[起] 展示当前被读者接受的"事实"（强化假象，让反转更有力）
[承] 制造紧张——当前认知下的困境加深（读者以为无解）
[转] 真相揭露（关键证据/人物的真实面目出现）
[合] 读者重新理解前文的片段 + 局势逆转
```

### 本章收益校验

- [ ] 前面有伏笔可以用（不是凭空反转）
- [ ] 反转改变了力量对比（不影响力量对比的反转=无效反转）
- [ ] 读者翻回去看前面的章节会觉得合理（不是cheat）

### 常见错误

- 没埋过伏笔就反转——这叫"作者说了算"，不叫反转
- 反转只影响配角不影响主线——反转必须改变主角的行动路径
- 反转解释太多——真相揭露本身就有力量，不需要大段解释

## 四、装逼

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **装逼场景** | 什么场合 | 恒太全员大会、保时捷门店、拍卖会 |
| **观众** | 谁在看（必须有观众） | 公司全员、前同事、竞争对手 |
| **伪装状态** | 主角被看到的表面 | 穿人字拖、被裁员的失败者、路人甲 |
| **真实实力** | 隐藏的底牌 | 千万现金、黑客权限、幕后大股东 |
| **展示方式** | 怎么露出实力 | 一句台词/一个动作/一条公告 |
| **震惊程度** | 观众反应分级 | ★=窃窃私语 ★★=全场安静 ★★★=有人腿软 |

### 起承转合锚点

```
[起] 主角以低姿态/日常态进入高规格场景
[承] 旁观者轻视/被忽视/被边缘化（蓄力）
[转] 一句台词或一个动作露出冰山一角 —— 全场安静
[合] 观众震惊/重新评估 → 主角若无其事离开/继续做下一件事
```

### 本章收益校验

- [ ] 观众有分级反应（不是"众人震惊了"一笔带过）
- [ ] 装逼方式符合主角性格（腹黑主角的装逼和热血主角不同）
- [ ] 装完之后有新信息进来（不能只为装而装——装完要有剧情推进）

### 常见错误

- 主角主动解释自己在装逼——最高级的装逼是不解释
- 观众全是路人甲——至少有一个关键人物在场（盟友/敌人/旧识）
- 装逼频率太高——装逼的爽感来自稀缺，连续装逼会钝化

## 五、冲突

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **冲突双方** | 主角 vs 谁 | 林白 vs 沈曜 |
| **冲突焦点** | 争的是什么 | 白昼控制权、资金来源合法性、离职协议 |
| **初始态势** | 谁占上风 | 沈曜控制银行/媒体/客户 |
| **冲突方式** | 什么形式的对抗 | 庭审对质/谈判桌/媒体战 |
| **转折武器** | 主角用来翻盘的筹码 | 合同漏洞镜、旧案证据链、舆论温度计 |
| **胜负判定** | 什么是"赢了" | 冻结解除/对方承认/旁观者倒戈 |

### 起承转合锚点

```
[起] 矛盾表面化——双方正面接触（会议/庭审/谈判开场）
[承] 主角被压制——对方出招，主角陷入被动（不能让主角一直赢）
[转] 主角掏出关键武器——局势翻转（证据/技能/第三方入场）
[合] 阶段性胜负 + 代价显现（赢了但付出了什么/对方还有后手）
```

### 本章收益校验

- [ ] 对方是有实力的对手（不是碾压弱鸡）
- [ ] 主角有被压制的时刻（没被压制过的胜利没有重量）
- [ ] 赢了之后有代价或新问题（不能"完美胜利"）

### 常见错误

- 对手智商掉线——强大的对手才有体面的胜利
- 冲突解决太快——一章就从冲突到解决会显得轻飘
- 主角赢的理由是"因为他是主角"——每次胜利必须有具体的策略/道具/人脉支撑

## 六、暧昧

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **情感对象** | 与谁产生暧昧 | 苏曼 |
| **当前关系状态** | 本章之前的关系温度 | 敌对/互相调查 (-3) |
| **触发事件** | 什么让关系变化 | 苏曼交出抽屉证据 |
| **暧昧信号** | 具体的肢体/语言/眼神细节 | "她手指在旧剪报上停了两次" |
| **关系变化幅度** | 从X度变到Y度 | -3 → -1（敌意减弱，产生好奇） |
| **第三人反应** | 有没有人注意到（增加真实感） | 陈胖子假装没看见 |

### 起承转合锚点

```
[起] 两人因任务/事件被迫近距离接触
[承] 试探/摩擦/言语交锋（明面上还在对抗，暗中有微妙关注）
[转] 一个意料之外的瞬间——对方展现出平时隐藏的一面
[合] 内心悄悄改观 + 表面上一切照旧（暧昧不能台词化，要画面化）
```

### 本章收益校验

- [ ] 关系有可感知的温度变化（-3→-1 比"感情加深"更准确）
- [ ] 不靠台词表白（靠动作、停顿、眼神）
- [ ] 至少有一个只属于这两人的细节（让读者觉得自己发现了秘密）

### 常见错误

- 内心独白过多——网文暧昧靠画面不靠独白
- 关系推进太快——从敌人到暧昧至少跨一卷
- 暧昧影响主线节奏——暧昧场景不该超过一章的30%

## 七、悬疑

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **谜题/疑问** | 本章要面对的核心悬念 | 万宝龙钢笔里藏了什么 |
| **已揭露的线索** | 本章读者知道了什么 | 钢笔曾被赵建国交给沈星来人 |
| **新产生的谜题** | 本章结尾抛出的新悬念 | 钢笔里的密钥能打开什么 |
| **信息获取方式** | 主角怎么得到线索 | 系统技能/角色供述/道具追踪 |
| **误导/红鲱鱼** | 有没有故意错误的引导 | （可选，不强求每章都有） |

### 起承转合锚点

```
[起] 发现异常/接到线索（主角注意到不对劲的地方）
[承] 追踪/调查（查资料/找人/调用技能）
[转] 发现关键线索——但不是答案，是更大谜题的入口
[合] 线索归档 + 新疑问浮出 + 下一步行动确定
```

### 本章收益校验

- [ ] 读者知道了一件之前不知道的事
- [ ] 这件事让主线更复杂而非更简单（好的悬疑是打开新问题）
- [ ] 获取线索有成本（时间/金钱/人情/技能消耗）

### 常见错误

- 谜题一直悬而不解——读者会忘
- 线索给得太碎——一章至少有一个可记住的线索
- 悬疑章没有爽感——可以不爽但必须有"原来如此"的智力快感

---

## 八、推进

### 逻辑控制台——特有字段

| 字段 | 说明 | 示例 |
|------|------|------|
| **推进对象** | 本章在推动什么 | 团队集结、场景迁移、时间跳跃 |
| **为哪个大事件铺垫** | 下一阶段的核心冲突是什么 | 沈星尽调、合同战 |
| **传递了什么信息** | 本章读者/角色知道了什么 | 资金流向异常、敌人部署 |
| **新设伏笔** | 本章埋了什么后续会用 | 某角色说了句暗示性的话 |
| **节奏控制** | 快/中/慢 | 中——信息量够但不过载 |

### 起承转合锚点

```
[起] 承接上章结尾，交代当前状态
[承] 信息传递/场景切换/角色汇合
[转] 一个小推进——一件具体的事被完成了
[合] 准备就绪——为下一章的大事件清空障碍
```

### 本章收益校验

- [ ] 至少推进了一个具体的状态变化（人/事/物到了新位置）
- [ ] 不空——没有"纯聊天"或"纯走路"章节
- [ ] 末尾有明确的"准备好了，可以开始了"信号

### 常见错误

- 推进章变成纯对话——用行动和细节带出信息，不要角色坐着开会
- 推进章太长了——2章以内的推进是合理的，超过3章就是拖戏
- 推进章没有小钩子——即便没有反转也该让读者想知道接下来发生什么

## 类型混用规则

一章可以有一个主类型 + 一个副类型，但必须主次分明。

| 组合 | 可行性 | 条件 |
|------|--------|------|
| 打脸 + 致富 | ✔ 推荐 | 打脸成功后系统播报收益 |
| 打脸 + 装逼 | ✔ 但注意别重复 | 打脸是反击对手，装逼是对观众——区分开 |
| 反转 + 打脸 | ✔ 推荐 | 先反转认知，再打脸反派 |
| 冲突 + 反转 | ✔ 推荐 | 冲突中出现意外信息=反转 |
| 暧昧 + 推进 | ✔ 允许 | 推进主线的同时微调情感线 |
| 悬疑 + 推进 | ✔ 允许 | 调查本身就是推进 |
| 打脸 + 打脸 | ✖ 禁止 | 一章只打一张脸 |
| 悬疑 + 反转 | ✖ 慎用 | 悬疑揭晓=反转，类型会重叠 |
| 装逼 + 致富 | ✖ 慎用 | 两个都是高潮型，一章塞不下 |

## 类型分布建议

一卷50章的类型配比参考：

| 类型 | 占比 | 每卷约 | 说明 |
|------|------|--------|------|
| 打脸 | 20-25% | 10-12章 | 主爽点来源，不能断 |
| 致富 | 10-15% | 5-8章 | 财富里程碑，每Phase至少1章 |
| 反转 | 10-12% | 5-6章 | 主要集中在Phase 3-4 |
| 装逼 | 8-10% | 4-5章 | 稀缺才有冲击力 |
| 冲突 | 15-20% | 8-10章 | Phase 4集中爆发 |
| 暧昧 | 5-8% | 3-4章 | 穿插在推进章中 |
| 悬疑 | 8-10% | 4-5章 | 每Phase 1章 |
| 推进 | 10-15% | 5-8章 | 每个Phase开篇和收尾 |
